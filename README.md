# Telegram Crawler MVP

Минимально жизнеспособный продукт (MVP) краулера для Telegram, который подписывается на каналы, собирает данные и предоставляет их в структурированном формате через удобный интерфейс Telegram-бота.

## 📌 Основные возможности

- 🤖 Управление через Telegram-бота
- 🔍 Поиск и добавление каналов по ключевым словам
- 📥 Автоматический сбор сообщений из каналов
- 📊 Структурирование и сохранение данных в MongoDB
- 🗂️ Группировка каналов для удобного управления
- 📤 Экспорт данных в JSON-формат
